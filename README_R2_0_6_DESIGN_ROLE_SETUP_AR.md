# HR Native Android R2.0.6 — Professional Design Refresh + App Icon + Device Role Setup

هذا التحديث يعمل فوق R2.0.5 ويستمر بنفس نظام APK الموقّع الذي تم تثبيته في R2.0.4.

## المضاف

- تحديث واضح على تصميم الواجهة الرئيسية والواجهات الداخلية.
- إضافة هوية بصرية أكثر احترافية مع ألوان ثابتة وواجهة Header موحدة.
- إضافة أيقونة تطبيق احترافية داخل المشروع عبر مجلدات mipmap.
- تغيير اسم التطبيق الظاهر إلى: نظام الموارد البشرية.
- إضافة شاشة تهيئة الجهاز عند أول تشغيل.
- تثبيت نوع الجهاز بصلاحيات واضحة:
  - مسؤول النظام.
  - مدير الموارد البشرية.
- حفظ نوع الجهاز محليًا داخل التطبيق.
- إضافة زر إعادة تهيئة الجهاز من الواجهة الرئيسية.
- تحديث الإصدار إلى R2.0.6.
- تحديث GitHub Actions ليخرج Artifact باسم:
  HRNativeAndroid-R2.0.6-signed-apk

## رموز التفعيل المحلية

- مسؤول النظام: 1001
- مدير الموارد البشرية: 2002

هذه الرموز محلية داخل التطبيق حاليًا، والغرض منها منع تغيير نوع الجهاز بالخطأ أثناء مرحلة التطوير.

## طريقة التركيب

انسخ محتويات هذا المجلد فوق مشروعك الحالي، ثم نفّذ:

```cmd
git add -A
git commit -m "HR Native Android R2.0.6 professional design role setup"
git push origin main
```

بعد نجاح GitHub Actions حمّل:

```text
HRNativeAndroid-R2.0.6-signed-apk
```

ثم ثبّت `app-release.apk` فوق R2.0.5 مباشرة.

## ملاحظة

لأن APK ما زال موقّعًا بنفس أسرار R2.0.4، يجب أن يثبت هذا الإصدار فوق السابق بدون حذف التطبيق.
