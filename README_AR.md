# HR Native Android R2.0.2

هذه حزمة بداية لتحويل تطبيق الموارد البشرية من WebView/Median إلى تطبيق Android Native.

## ماذا تحتوي هذه النسخة؟

- مشروع Android Studio كامل كبداية Native.
- واجهة رئيسية مشابهة لترتيب النسخة الحالية.
- واجهة ملاحظات مدير الموارد البشرية بتصميم احترافي قريب من R1.4.88.
- اختيار المستخدم الحالي: مسؤول النظام / مدير الموارد البشرية.
- نموذج إرسال ملاحظة من مدير الموارد البشرية.
- بحث موظف لا يعرض كل الأسماء عند الضغط، بل يبدأ بعد كتابة حرفين.
- تعبئة الشعبة الحالية عند اختيار الموظف.
- سجل ملاحظات مع فلاتر وبطاقات وشارات.
- زر تمت المراجعة في وضع مسؤول النظام ضمن النموذج الأولي.

## ماذا لا تحتوي بعد؟

هذه نسخة أساس وليست النسخة النهائية. لم يتم بعد ربط:

- بيانات GitHub Excel/JSON الحقيقية.
- Google Sheet / Apps Script.
- Firebase Cloud Messaging.
- تصدير PDF.
- قاعدة بيانات محلية Room/SQLite.

هذه العناصر تنفذ في المراحل التالية R2.0.2 وما بعدها.

## طريقة الفتح

1. افتح Android Studio.
2. اختر Open.
3. اختر مجلد `HRNativeAndroid_R2_0_1`.
4. انتظر Gradle Sync.
5. شغل التطبيق على Emulator أو هاتف Android.

## ملاحظة مهمة حول اسم الحزمة

اسم الحزمة الحالي للاختبار:

`iq.hr.mobile.nativeapp`

هذا يعني أن التطبيق سيُثبت كتطبيق جديد منفصل عن نسخة Median الحالية. لاحقًا، عند اعتماد النسخة النهائية، نقرر هل نبقيه بهذا الاسم أو نستخدم اسم الحزمة القديم مع توقيع مناسب.

## تشغيل أخف من Android Studio

تمت إضافة GitHub Actions حتى يتم بناء APK على GitHub بدل جهازك.
راجع الملف:

`README_VSCODE_GITHUB_ACTIONS_AR.md`

المجلد المهم للبناء:

`.github/workflows/build-apk.yml`

بهذا تستطيع فتح المشروع في VS Code فقط، ثم رفعه إلى GitHub، وتحميل APK من تبويب Actions.
