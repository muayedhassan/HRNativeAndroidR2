# HR Native Android R2.13.0

## Five Suite Upgrade

هذا الإصدار يجمع خمس حزم تحديثات ظاهرة داخل التطبيق حتى يكون الفرق واضحًا في الواجهة والاستخدام اليومي.

## الحزمة 1: Home Command Center

- إضافة مركز جديد في الرئيسية باسم حزمة التحديثات الخمس.
- كروت صغيرة وسريعة لفتح:
  - الرئيسية
  - السجل
  - الملف
  - الملاحظات
  - النظام
  - التحديث
- تحديث تذييل الرئيسية ليعرض هوية R2.13.0.

## الحزمة 2: Directory Board

- إضافة لوحة تشغيل داخل سجل الموظفين.
- عرض أرقام الدائم والعقد ضمن النطاق الحالي.
- عرض أفضل شعبة بشكل مختصر.
- أزرار مباشرة لعرض النواقص، كل الشعب، وتحديث البيانات.

## الحزمة 3: Executive 360+

- إضافة خلاصة تنفيذية داخل ملف الموظف.
- عرض حالة الملف، الهوية، الراتب، التعيين، التعليم، وآخر تحديث.
- إبقاء تبويبات الملف السابقة مع تحسين القراءة قبل الدخول للتفاصيل.

## الحزمة 4: Notes Studio

- إضافة لوحة تحليل للملاحظات.
- عرض عدد حركات النقل، التنسيب، إنهاء التنسيب، والملاحظات الإدارية.
- عرض الجديد والمراجع مع مؤشر جاهزية سجل الملاحظات.

## الحزمة 5: System Health Cockpit

- إضافة لوحة تشخيص في شاشة حالة النظام.
- عرض الإصدار، الدور، التوقيع، عدد الموظفين، الجودة، وحالة التحديث.
- إضافة خارطة R2.13.0 داخل مركز التحديث.

## ملفات الإصدار

- `versionCode`: 23
- `versionName`: 2.13.0
- Artifact في GitHub Actions:
  `HRNativeAndroid-R2.13.0-five-suite-upgrade-signed-apk`

## طريقة التحديث من VS Code

1. فك ملف Patch zip فوق مجلد المشروع `HRNativeAndroidR2`.
2. افتح Terminal داخل VS Code.
3. نفذ:

```bash
git add -A
git commit -m "R2.13.0 five suite upgrade"
git push
```

4. افتح GitHub Actions.
5. انتظر نجاح Build Android Signed APK.
6. حمّل Artifact:
   `HRNativeAndroid-R2.13.0-five-suite-upgrade-signed-apk`
7. افتح الملف داخله:
   `app-release.apk`
8. ثبّته فوق النسخة الموجودة على الهاتف.

مهم: استخدم فقط `app-release.apk` الناتج من GitHub Actions لأن التوقيع ثابت.
