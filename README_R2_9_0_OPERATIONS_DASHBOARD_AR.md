# HR Native Android R2.9.0

## Operations Dashboard Refresh

هذا التحديث يعمل طفرة ظاهرة في الشاشة الرئيسية للتطبيق، بحيث لا تبدأ الواجهة بقائمة وبحث فقط، بل تبدأ بـ **غرفة سيطرة تشغيلية** تعرض حالة النظام والبيانات مباشرة.

## أهم التغييرات

- شاشة رئيسية جديدة بنمط غرفة سيطرة.
- لوحة حالة البيانات والتزامن.
- مركز جودة بيانات يعرض:
  - متوسط اكتمال ملفات الموظفين.
  - عدد الملفات التي تحتاج مراجعة.
  - شريط تقدم لاكتمال السجل العام.
- لوحة توزيع الشعب الأكثر ظهورًا في بيانات الموظفين.
- عرض آخر ملاحظات المدير داخل الرئيسية.
- إبقاء بحث الموظفين السريع في الرئيسية.
- إبقاء بطاقة الموظف ذات التبويبات من R2.8.0.
- إبقاء مركز التحديث الذكي من R2.7.0.
- إصلاح AndroidX مدمج داخل `gradle.properties`.

## رقم الإصدار

- `versionCode`: 19
- `versionName`: 2.9.0
- اسم Artifact المتوقع من GitHub Actions:
  `HRNativeAndroid-R2.9.0-operations-dashboard-signed-apk`

## طريقة التحديث من VS Code

1. فك ضغط ملف Patch فوق مشروع `HRNativeAndroidR2`.
2. من Terminal داخل VS Code نفذ:

```bash
git status
git add -A
git commit -m "R2.9.0 operations dashboard refresh"
git push
```

3. افتح GitHub Actions وانتظر اكتمال البناء.
4. حمّل Artifact:
   `HRNativeAndroid-R2.9.0-operations-dashboard-signed-apk`
5. ثبّت الملف الموجود داخله:
   `app-release.apk`

مهم: استخدم APK الموقع الناتج من GitHub Actions فقط حتى يثبت فوق النسخة الموجودة بدون حذف.

## ملاحظة

هذا التحديث يغيّر أول شاشة بشكل واضح، لذلك يفترض أن تظهر الفروقات مباشرة بعد فتح التطبيق.
