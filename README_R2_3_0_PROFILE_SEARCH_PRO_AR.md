# HR Native Android R2.3.0 — Profile Search Pro

هذا التحديث يركز على جعل شاشة البحث وبطاقة الموظف أقرب بصريًا ووظيفيًا إلى نسخة الويب، مع إبقاء التطبيق Native Android بالكامل.

## الجديد

- ترقية الإصدار إلى `R2.3.0`.
- تحسين نتائج البحث ببطاقات موظفين احترافية.
- إضافة أحرف مختصرة للموظف داخل البطاقة.
- إظهار نوع التوظيف والرقم الوظيفي ونسبة اكتمال الملف داخل نتيجة البحث.
- إعادة بناء بطاقة الموظف بهيدر رسمي قريب من نسخة الويب.
- إضافة مؤشرات:
  - اكتمال الملف.
  - عدد النواقص.
  - الرقم الوظيفي.
  - نوع التوظيف.
- إضافة مركز جودة البيانات داخل بطاقة الموظف.
- تقسيم بيانات الموظف إلى:
  - البيانات الأساسية.
  - البيانات الوظيفية.
  - الهوية الشخصية.
  - معلومات إضافية.
- تحديث مركز التحديث داخل التطبيق ليعرض محتوى R2.3.0.

## الخطوط والهوية

- النص العربي: `SF Sultan`.
- العناوين: `Ya Modern Pro`.
- الأرقام: `Stencil`.
- الهوية البصرية مستمرة بنفس ألوان R2.2.0 مع تحسينات واضحة في بطاقة الموظف.

## آلية التحديث المعتمدة

1. فك ملف Patch zip فوق مشروع `HRNativeAndroidR2`.
2. نفذ:

```bash
git add -A
git commit -m "HR Native Android R2.3.0 profile search pro update"
git push
```

3. افتح GitHub Actions وانتظر نجاح البناء.
4. حمّل Artifact:

```text
HRNativeAndroid-R2.3.0-profile-search-pro-signed-apk
```

5. ثبّت `app-release.apk` فوق النسخة السابقة مباشرة.

مهم: استخدم فقط APK الناتج من GitHub Actions لأن توقيعه ثابت.
