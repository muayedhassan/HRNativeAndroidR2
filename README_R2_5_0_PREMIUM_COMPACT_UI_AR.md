# HR Native Android R2.5.0 — Premium Compact UI

هذا تحديث واجهة كبير بعد R2.4.0، هدفه جعل التطبيق أرتب وأخف وأكثر احترافية، مع كروت أصغر وأحجام خط منسقة وتأثيرات Native أوضح.

## الفكرة العامة

تحويل الواجهة من كروت كبيرة إلى تصميم Compact Premium:

- كروت أصغر وأكثر كثافة.
- خطوط بأحجام أهدأ.
- تدرجات لونية داخل الهيدر والكروت.
- ظلال Elevation للكروت.
- أيقونات داخل فقاعات متدرجة.
- شارات أصغر داخل بطاقات الموظفين.
- نتائج بحث أخف وأسهل للقراءة.

## التغييرات الكبيرة

- تصغير الصفحة الرئيسية بالكامل:
  - الهيدر.
  - مؤشرات الموظفين.
  - لوحة حالة البيانات.
  - كروت مركز العمليات.
- تحويل كروت مركز العمليات إلى وحدات Compact بحجم أصغر.
- تحسين فقاعات الأيقونات حتى تتناسب مع حجم الكرت.
- إضافة دالة `gradient` لاستخدام تدرجات Native في الواجهة.
- إضافة Elevation للكروت لإعطاء عمق بصري.
- تصغير بطاقة الموظف في نتائج البحث.
- تصغير الشارات والأزرار والعناوين.
- تحسين بطاقة ملف الموظف ومركز جودة البيانات بأحجام أخف.
- تحديث مركز التحديث داخل التطبيق إلى R2.5.0.

## آلية التحديث المعتمدة

1. فك ملف Patch zip فوق مشروع `HRNativeAndroidR2`.
2. نفذ:

```bash
git add -A
git commit -m "HR Native Android R2.5.0 premium compact UI"
git push
```

3. افتح GitHub Actions وانتظر نجاح البناء.
4. حمّل Artifact:

```text
HRNativeAndroid-R2.5.0-premium-compact-ui-signed-apk
```

5. ثبّت `app-release.apk` فوق النسخة السابقة مباشرة.

مهم: استخدم فقط APK الناتج من GitHub Actions لأن توقيعه ثابت.
