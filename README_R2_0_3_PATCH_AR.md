# HR Native Android R2.0.3 — Employee Profile Card Fix

هذا التحديث يعالج ملاحظة أن البحث يظهر النتائج لكن لا توجد بطاقة موظف مستقلة واضحة.

## المضاف

- إضافة شاشة بطاقة موظف تفصيلية عند الضغط على نتيجة البحث.
- زر واضح: **فتح بطاقة الموظف** داخل كل نتيجة.
- بطاقة تحتوي أقسامًا مرتبة:
  - المعلومات الوظيفية.
  - المعلومات الشخصية والهوية.
  - التحصيل والتخصص.
  - التعيين والملاحظات.
- جلب حقول إضافية من JSON مثل الجنس، الاختصاص، تاريخ الولادة، تاريخ إصدار الهوية، جهة الإصدار، الملاحظات، وآخر تحديث.
- زر اختيار الموظف مباشرة داخل ملاحظات المدير من بطاقة الموظف.
- تحديث الإصدار إلى R2.0.3.

## طريقة التركيب

انسخ محتويات هذا المجلد فوق مشروعك الحالي، ثم نفذ:

```cmd
git add -A
git commit -m "HR Native Android R2.0.3 employee profile card fix"
git push origin main
```
