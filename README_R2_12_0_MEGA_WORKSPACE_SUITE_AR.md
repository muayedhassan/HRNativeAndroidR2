# HR Native Android R2.12.0

## Mega Workspace Suite

هذا التحديث يجمع ثلاث ترقيات كبيرة داخل تحديث واحد حتى تكون النقلة واضحة داخل نسخة Android Native.

## 1. Employee Directory Pro

- سجل الموظفين أصبح باسم سجل الموظفين Pro.
- إضافة فلتر الشعب الذكي حسب أكثر الشعب ظهورًا في البيانات.
- دمج فلتر النوع مع فلتر الشعبة:
  - الكل
  - دائم
  - عقد
  - نواقص
  - كل الشعب أو شعبة محددة
- إضافة لوحة قراءة للنطاق الحالي:
  - عدد الموظفين ضمن النطاق
  - متوسط جودة الملفات
  - عدد الملفات الناقصة
- البحث يعرض نطاق البحث الحالي بشكل أوضح.

## 2. Employee Profile 360

- إضافة شريط ملف الموظف 360 أعلى بطاقة الموظف.
- إضافة مؤشرات فورية:
  - اكتمال الملف
  - عدد النواقص
  - نوع التوظيف
- إضافة تبويب جديد باسم مسار.
- تبويب مسار يعرض:
  - تاريخ التعيين
  - الموقع الإداري
  - الدرجة والمرحلة
  - جودة الملف
  - آخر تحديث
- إضافة أزرار أسرع للجودة والمسار والملاحظات.

## 3. Admin & Quality Analytics

- توسيع لوحة مسؤول النظام.
- إضافة تحليلات الإدارة والجودة:
  - جودة عامة
  - ملفات تحتاج مراجعة
  - ملاحظات جديدة
  - أكثر حقل ناقص
- إضافة مصفوفة القرار السريع:
  - مراجعة الملاحظات
  - ملفات ناقصة
  - مركز الجودة
  - مركز التحديث
- إضافة طابور مراجعة يعرض أول الملاحظات الجديدة.

## ملفات الإصدار

- `versionCode`: 22
- `versionName`: 2.12.0
- Artifact في GitHub Actions:
  `HRNativeAndroid-R2.12.0-mega-workspace-suite-signed-apk`

## طريقة التحديث من VS Code

1. فك ملف Patch zip فوق مجلد المشروع `HRNativeAndroidR2`.
2. افتح Terminal داخل VS Code.
3. نفذ:

```bash
git add -A
git commit -m "R2.12.0 mega workspace suite"
git push
```

4. افتح GitHub Actions.
5. انتظر نجاح Build Android Signed APK.
6. حمّل Artifact:
   `HRNativeAndroid-R2.12.0-mega-workspace-suite-signed-apk`
7. افتح الملف داخله:
   `app-release.apk`
8. ثبّته فوق النسخة الموجودة على الهاتف بدون حذف التطبيق.

مهم: استخدم فقط `app-release.apk` الناتج من GitHub Actions لأن التوقيع ثابت.
