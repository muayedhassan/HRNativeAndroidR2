# HR Native Android R2.8.0

## Employee ID Card + Native Profile Tabs

هذا التحديث يركز على تغيير واضح داخل شاشة ملف الموظف، بحيث تصبح أقرب إلى تجربة نسخة الويب:

- بطاقة هوية وظيفية كبيرة أعلى الملف.
- تبويبات Native داخل بطاقة الموظف:
  - وظيفة
  - هوية
  - تعليم
  - جودة
  - ملاحظات
- مربعات معلومات صغيرة بدل النص الطويل.
- عرض اكتمال الملف والنواقص داخل تبويب جودة.
- اختيار الموظف مباشرة لملاحظات المدير.
- الحفاظ على مركز التحديث الذكي المضاف في R2.7.0.

## رقم الإصدار

- `versionCode`: 18
- `versionName`: 2.8.0
- اسم Artifact المتوقع من GitHub Actions:
  `HRNativeAndroid-R2.8.0-employee-id-card-tabs-signed-apk`

## طريقة التحديث المعتادة

1. فك ضغط ملف Patch داخل مشروع `HRNativeAndroidR2`.
2. ارفع الملفات إلى GitHub على فرع `main` أو `master`.
3. افتح GitHub Actions وانتظر اكتمال البناء.
4. حمّل Artifact:
   `HRNativeAndroid-R2.8.0-employee-id-card-tabs-signed-apk`
5. ثبّت الملف الموجود داخله:
   `app-release.apk`

مهم: استخدم APK الموقع الناتج من GitHub Actions فقط حتى يثبت فوق النسخة الموجودة على الهاتف بدون حذف.

## مركز التحديث داخل التطبيق

ملف `latest.json` تم تحديثه إلى R2.8.0. عند نشر إصدار أحدث لاحقاً، ضع رابط APK مباشر في `apkUrl` حتى يستطيع مركز التحديث داخل التطبيق اكتشاف النسخة الجديدة وتنزيلها.
