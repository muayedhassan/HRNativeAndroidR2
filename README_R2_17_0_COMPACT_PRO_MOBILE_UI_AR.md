# R2.17.0 - Compact Pro Mobile UI

هذا التحديث يركز على جعل واجهة Android Native أخف وأقرب لتطبيق موبايل احترافي، مع الحفاظ على فكرة نسخة الويب: نطاق السجل، أقسام البرنامج، إخفاء الشريط العلوي، وواجهة الكرت المختار.

## أهم التغييرات

- تصغير كروت نطاق السجل وأقسام البرنامج حتى تظهر بشكل أكثر ترتيبًا على شاشة الهاتف.
- تقليل المسافات الداخلية والارتفاعات الزائدة في الصفحة الرئيسية.
- تحسين الهيدر ليكون أوضح وأخف بدون أخذ مساحة كبيرة من الشاشة.
- اعتماد خط جسم أخف للقراءة اليومية بدل الخط الأسود الثقيل في النصوص الصغيرة.
- إبقاء العناوين بخط Ya Modern Pro، والأرقام بخط Stencil.
- تحسين تمييز الكرت المختار بلمسة ذهبية أكثر هدوءًا.
- إضافة تأثير ضغط Ripple للكروت الرئيسية وقائمة الموظفين.
- تحسين واجهة الإخفاء: شريط علوي أصغر، مؤشرات أقل حجمًا، وقائمة موظفين أكثر كثافة.
