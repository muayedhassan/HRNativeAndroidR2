# HR Native Android R2.4.0 — Command Center Redesign

هذا تحديث واجهة كبير، هدفه نقل تطبيق Android Native من تحسينات جزئية إلى واجهة تشغيل احترافية أقرب لنسخة الويب.

## الفكرة العامة

تم تحويل الصفحة الرئيسية إلى Command Center واضح:

- ثيم داكن رسمي قريب من نسخة الويب.
- هيدر تنفيذي جديد باسم النظام والإصدار.
- مؤشرات كبيرة للموظفين والدائميين والعقود.
- لوحة حالة بيانات وتزامن.
- كروت تشغيل كبيرة بأيقونات Native.
- هيدرات جديدة للشاشات الأساسية بأيقونات وخط فاصل.

## التغييرات الكبيرة

- إضافة أيقونات Vector داخل المشروع:
  - الموظفين.
  - البحث.
  - ملاحظات المدير.
  - مسؤول النظام.
  - التحديث.
  - جودة البيانات.
  - ملف الموظف.
  - التزامن.
- إعادة تصميم الشاشة الرئيسية بالكامل.
- تحويل الألوان إلى هوية داكنة ملكية مع الذهبي والأخضر والبنفسجي.
- إعادة تصميم كروت الوحدات الرئيسية.
- تحسين أزرار Outline وChips لتناسب الثيم الداكن.
- تحديث هيدرات:
  - سجل الموظفين.
  - حالة النظام.
  - لوحة مسؤول النظام.
  - مركز تحديث التطبيق.
  - ملاحظات مدير الموارد البشرية.
- الحفاظ على خطوط:
  - `SF Sultan` للنصوص العربية.
  - `Ya Modern Pro` للعناوين.
  - `Stencil` للأرقام.

## أرقام الإصدار

## Artifact المتوقع من GitHub Actions

```text
HRNativeAndroid-R2.4.0-command-center-redesign-signed-apk
```

داخله:

```text

```

## آلية التحديث المعتمدة

1. فك ملف Patch zip فوق مشروع `HRNativeAndroidR2`.
2. نفذ:

```bash
git add -A
git commit -m "HR Native Android R2.4.0 command center redesign"
git push
```

3. افتح GitHub Actions وانتظر نجاح البناء.
4. حمّل Artifact:

```text
HRNativeAndroid-R2.4.0-command-center-redesign-signed-apk
```

5. ثبّت `app-release.apk` فوق النسخة السابقة مباشرة.

مهم: استخدم فقط APK الناتج من GitHub Actions لأن توقيعه ثابت.
