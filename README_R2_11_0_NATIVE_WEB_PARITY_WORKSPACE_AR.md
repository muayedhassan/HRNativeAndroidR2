# HR Native Android R2.11.0

## Native Web Parity Workspace

هذا التحديث يوسع التطبيق بشكل أكبر ويقربه أكثر من تنظيم نسخة الويب، من خلال إنشاء مساحة عمل Native موحدة بين الشاشات الأساسية.

## أهم التغييرات

- شريط تنقل موحد داخل التطبيق:
  - الرئيسية
  - الموظفون
  - الجودة
  - الملاحظات
  - الإدارة
  - النظام
  - التحديث
- مركز جودة بيانات مستقل.
- فلتر جديد داخل سجل الموظفين باسم `نواقص`.
- ملخص جديد داخل سجل الموظفين:
  - النطاق الحالي
  - عدد النتائج
  - عدد الملفات الناقصة
- صفحة جودة تعرض:
  - متوسط اكتمال الملفات
  - أكثر الحقول الناقصة
  - أول الموظفين الذين تحتاج ملفاتهم مراجعة
- شاشة حالة النظام أصبحت أوسع وتعرض:
  - نوع الجهاز
  - جودة البيانات
  - عدد الملاحظات
- بقاء تحديثات R2.10.0 الخاصة بملاحظات المدير.
- بقاء غرفة السيطرة من R2.9.0.
- بقاء بطاقة الموظف ذات التبويبات من R2.8.0.
- إصلاح AndroidX مدمج.

## رقم الإصدار

- `versionCode`: 21
- `versionName`: 2.11.0
- اسم Artifact المتوقع من GitHub Actions:
  `HRNativeAndroid-R2.11.0-native-web-parity-workspace-signed-apk`

## طريقة التحديث من VS Code

1. فك ضغط ملف Patch فوق مشروع `HRNativeAndroidR2`.
2. من Terminal داخل VS Code نفذ:

```bash
git status
git add -A
git commit -m "R2.11.0 native web parity workspace"
git push
```

3. افتح GitHub Actions وانتظر اكتمال البناء.
4. حمّل Artifact:
   `HRNativeAndroid-R2.11.0-native-web-parity-workspace-signed-apk`
5. ثبّت الملف الموجود داخله:
   `app-release.apk`

مهم: استخدم APK الموقع الناتج من GitHub Actions فقط حتى يثبت فوق النسخة الموجودة بدون حذف.
